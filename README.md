# TypeRush ⚡

TypeRush is a simple typing game designed to test and improve your typing speed and accuracy.

## Features

* Real-time typing
* WPM and accuracy tracking
* Random typing challenges
* Score tracking
* Simple responsive UI

## Tech

Built with HTML, CSS, and JavaScript.
